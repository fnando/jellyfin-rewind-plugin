Scrobble rules

Every playback session is recorded. These rules decide which ones count as a scrobble (what /Rewind/History returns by default). A play counts when it reaches the percentage of the runtime or the minutes actually played, whichever comes first; 0 disables either half. Furthest position counts resumed plays (Trakt style); time played only counts what was played in that session, seeks excluded (Last.fm style).
